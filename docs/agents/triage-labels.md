# Triage Labels

The engineering skills use five canonical triage states. This repository uses the same names in GitHub.

| Canonical state   | GitHub label      | Meaning                                        |
| ----------------- | ----------------- | ---------------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer needs to evaluate the issue         |
| `needs-info`      | `needs-info`      | Waiting for more information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent         |
| `ready-for-human` | `ready-for-human` | Requires human implementation or judgment      |
| `wontfix`         | `wontfix`         | Will not be actioned                           |

When a skill names a canonical state, apply the matching GitHub label from this table.
